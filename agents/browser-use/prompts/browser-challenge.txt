Complete all 30 steps of the browser challenge.

PATTERN FOR EACH STEP:
1. Look at the page to understand what's needed
2. Find the 6-character alphanumeric code (scroll if needed, click reveal buttons)
3. Enter the code in the input field and click "Submit Code"
4. Wait for the page to advance, then repeat

KEY RULES:
- NEVER click decoy buttons: "Next Page", "Go Forward", "Continue", "Next Step", "Click Me", etc.
- ONLY click "Submit Code" button to advance
- Each step may require different actions: scrolling, hovering, dragging, keyboard shortcuts
- Use visual understanding to identify what the step requires

TOOLS FOR DIFFERENT CHALLENGES:
- scroll(down=True, pages=N) - reveal hidden content
- hover(index=N) - reveal hover-triggered content
- drag(source=N, target=M) - drag-and-drop puzzles
- draw(index=N, strokes=3) - canvas/signature challenges
- send_keys("ArrowUp ArrowDown") - keyboard challenges
- evaluate("window.__skills.search_dom({text:'pattern'})") - find hidden elements

NEVER call done() until all 30 steps are complete.
