## Finding Hidden Codes

Codes are 6-character alphanumeric strings (like `A7BK3X`). Use skills to find them:
- `window.__skills.interact()` — scans all hiding spots automatically
- `window.__skills.extract_hidden()` — extracts hidden text from DOM

## Challenge Types

- **Click**: Click action buttons (Reveal Code, Start, Play Audio, Capture, etc.)
- **Click box**: Some challenges say "click here N times" — click the challenge box div
- **Hover**: Hold mouse over colored areas for 1-2s (scroll element into view first)
- **Scroll**: Scroll down 500-800px to reveal content
- **Keyboard**: Press key sequences shown on page — use send_keys action (e.g. "Control+a Control+c Control+v")
- **Drag-drop**: Drag tiles to drop zones with mouse.down/move/up — drag ALL tiles, not just one
- **Canvas**: Draw strokes on canvas, then click Complete
- **Math**: Solve expression, fill answer in input, click Solve
- **Service worker**: Click Register → wait 4s → click Retrieve
- **Shadow DOM**: Click through nested levels
- **Wait**: Some codes appear after a timer — just wait

## After Any Interaction

If a code is found, enter it in the code input and click "Submit Code".
